# AiTechX Landing Page

This is a simple, responsive landing page for AiTechX, a fictional company that provides web development, social media advertising, and WhatsApp automation services.

## Features

-   **Responsive Design:** The landing page is designed to work on all devices, from mobile phones to desktops.
-   **Services Section:** A dedicated section to showcase the services offered by AiTechX.
-   **Contact Form:** A simple contact form that uses a `mailto:` link to send inquiries.
-   **SEO Friendly:** The page includes meta tags for description and keywords to improve search engine visibility.
-   **Animations:** Subtle animations on service cards to improve user experience.

## How to Use

1.  Clone the repository.
2.  Open the `aitechx-landing-page/index.html` file in your web browser.

## Customization

-   **Contact Form:** To receive inquiries from the contact form, you need to change the email address in the `action` attribute of the form in `index.html`.
    ```html
    <form id="contact-form" action="mailto:your-email@example.com" method="post" enctype="text/plain">
    ```
    Replace `your-email@example.com` with your own email address.

-   **Content:** You can change the content of the landing page by editing the `index.html` file.

-   **Styling:** You can customize the styling of the landing page by editing the `css/style.css` file.
